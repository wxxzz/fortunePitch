# FortunePitch 需求文档

> 内部开发代号:致富之道 (The Path to Wealth)
> 对外正式工程名:FortunePitch (财富绿茵)

## 1. 产品定位

基于大数据与 AI 的**足彩数据分析与辅助决策工具**。系统通过对历史比赛数据、
赔率数据的量化建模,输出可解释的概率预测,帮助用户理解比赛,而非替用户做决定。

**合规底线**:系统不提供任何投注建议,不做非法博彩导流。

## 2. 核心功能模块

| 模块 | 功能 | 状态 |
|------|------|------|
| 赛事中心 | 展示在售/近期赛事,运行泊松模型输出比分分布 | 初版 |
| 赔率走势 | 欧赔时间序列可视化,识别市场预期变化 | 初版(演示数据) |
| 复盘中心 | 历史预测 vs 实际结果回溯,统计命中率 | 初版(演示数据) |
| SHAP 归因 | 模型预测的特征归因分析,保证可解释性 | 初版(演示数据) |

## 3. 待规划功能

- 实时数据源接入(比赛、赔率、射门事件)
- Elo 评分体系全量回测
- 滚球(In-Play / Live Odds)实时分析
- 凯利指数(Kelly Criterion)资金管理分析

## 4. 非功能需求

- 所有 AI 结论必须可解释(SHAP 归因)
- 后端接口全量类型提示 + Pydantic 校验
- 核心算法测试覆盖率 >= 80%
