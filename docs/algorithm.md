# FortunePitch 算法说明文档

> 代码位置:`backend/app/services/`

## 1. Elo 评分(`elo.py`)

衡量球队实力的经典评分体系,随比赛结果动态更新。

$$E_{home} = \frac{1}{1 + 10^{(R_{away} - R_{home} - HFA)/400}}$$

$$R' = R + K \cdot (S - E)$$

- `HFA`(Home Field Advantage):主场优势,默认 100 Elo 分
- `K`:更新系数,默认 20
- `S`:实际得分(胜 1 / 平 0.5 / 负 0)

性质:更新是零和的(双方评分之和守恒)。

## 2. xG 预期进球(`xg.py`)

基于射门位置与类型的 Logistic 回归模型:

$$xG = \sigma(b_0 + b_1 d + b_2 \theta + b_3 \cdot \text{isHeader})$$

- `d`:射门点到球门中心的欧氏距离(米)
- `θ`:射门点对两根门柱的张角(弧度)
- 系数 `b0..b3` 需由历史射门数据拟合,当前默认值为演示用

球队总 xG = 各次射门 xG 之和,是进球期望的无偏估计。

## 3. Dixon-Coles 泊松模型(`poisson.py`)

将比分建模为两个泊松分布并做低比分相关性修正:

$$P(i, j) = \tau(i, j; \lambda, \mu, \rho) \cdot \text{Pois}(i; \lambda) \cdot \text{Pois}(j; \mu)$$

`τ` 修正项仅在 (0,0) (0,1) (1,0) (1,1) 四个比分生效,
校正独立泊松假设对平局与一球小胜的系统性低估;
`λ / μ`(主客期望进球)可由 xG 直接给出,`ρ` 默认 -0.10。

由比分矩阵可导出:胜平负概率、Top 比分、总进球期望。

## 4. 凯利指数(`poisson.py::kelly_fraction`)

衡量模型概率与市场赔率的偏差:

$$f^* = \frac{p \cdot odds - 1}{odds - 1}$$

结果为负表示无正期望,系统统一返回 0。
**该指标仅用于量化分析与教学演示,不构成任何投注建议。**

## 5. 后续规划

- xG 系数拟合管道(历史射门数据回归)
- Elo → λ/μ 换算(当前泊松输入直接来自 xG)
- SHAP 归因接入真实模型(如梯度提升树)
