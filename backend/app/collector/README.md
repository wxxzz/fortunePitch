# 数据采集模块(Collector)

从外部数据源拉取原始数据,清洗转换后写入 `fp_*` 业务表。

## 目录规划(待实现)

| 子模块 | 职责 |
|--------|------|
| `sources/` | 各数据源适配器(赛程赛果、球队球员档案、实时比分、历史赔率) |
| `parsers/` | 原始响应 -> 领域对象的清洗与映射(队名标准化、时间时区归一) |
| `sync/` | 调度与同步策略(全量初始化、增量更新、定时任务) |
| `registry.py` | 数据源注册与统一入口 |

## 约束

- 只使用 `requirements.txt` 中已存在的库;新增依赖需先确认
- 采集失败必须显式记录,不允许静默吞错
- 写库复用 `app.core.database` 会话与 `app.services.crud` 通用逻辑
- 对外展示一律使用 "FortunePitch" 品牌名
- 系统定位为数据分析工具,采集内容不含任何投注引导信息

实现逻辑待明确后按上述规划填充,不保留占位函数。
